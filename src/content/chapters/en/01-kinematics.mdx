The arm's configuration is a pair of joint angles. It is convenient to write it as a point on a torus:

<Eq display math="q = (q_1, q_2) in cal(Q) subset.eq bb(R)^2" />

If the link lengths are <Eq math="l_1" /> and <Eq math="l_2" />, forward kinematics gives the gripper position:

<Eq display math="vec(x, y) = vec(l_1 cos(q_1) + l_2 cos(q_1 + q_2), l_1 sin(q_1) + l_2 sin(q_1 + q_2))" />

The geometry matches the figure: the first link rotates by <Eq math="q_1" />, the second by an additional <Eq math="q_2" /> relative to the first.

## Python code

The same law in NumPy. Below is a fragment with the trigonometric lines highlighted:

```python title="fk.py" {6-9}
import numpy as np

def fk(q, l1, l2):
    q1, q2 = q
    x = l1 * np.cos(q1) + l2 * np.cos(q1 + q2)
    y = l1 * np.sin(q1) + l2 * np.sin(q1 + q2)
    return np.array([x, y])
```
