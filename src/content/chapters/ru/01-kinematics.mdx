Конфигурация руки — пара углов в суставах. Её удобно писать как точку на торе:

<Eq display math="q = (q_1, q_2) in cal(Q) subset.eq bb(R)^2" />

Если длины звеньев <Eq math="l_1" /> и <Eq math="l_2" />, прямая задача кинематики даёт положение схвата:

<Eq display math="vec(x, y) = vec(l_1 cos(q_1) + l_2 cos(q_1 + q_2), l_1 sin(q_1) + l_2 sin(q_1 + q_2))" />

Геометрия та же, что на схеме: первое звено поворачивается на <Eq math="q_1" />, второе — ещё на <Eq math="q_2" /> относительно первого.

## Код на Python

Тот же закон в NumPy. Ниже — фрагмент с акцентом на строки с тригонометрией:

```python title="fk.py" {6-9}
import numpy as np

def fk(q, l1, l2):
    q1, q2 = q
    x = l1 * np.cos(q1) + l2 * np.cos(q1 + q2)
    y = l1 * np.sin(q1) + l2 * np.sin(q1 + q2)
    return np.array([x, y])
```

Полный файл живёт в `examples/` и вставляется как есть — его можно гонять отдельно от сайта:

<Code code={fk} lang="python" title="examples/fk.py" />

Короткий запуск из терминала:

```bash
python examples/fk.py
```
