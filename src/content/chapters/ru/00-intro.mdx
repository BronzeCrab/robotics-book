## Углы

В формулах и в коде углы — **радианы**, пока явно не сказано иное. Полный оборот — <Eq math="2 pi" />. Градусы оставляем подписям и ползункам на картинках.

<Eq display math="38 degree = 38 pi / 180" />

В NumPy перевод такой:

```python
import numpy as np

np.deg2rad(38)
np.rad2deg(0.66)
```

## Конфигурация и векторы

Состояние манипулятора — набор координат суставов. Это точка конфигурационного пространства:

<Eq display math="q = (q_1, dots, q_n) in bb(R)^n" />

Для плоского 2R будет <Eq math="n = 2" />. Положение схвата на плоскости — обычная точка:

<Eq display math="p = vec(x, y) in bb(R)^2" />

В тексте <Eq math="q" /> и <Eq math="p" /> — векторы. В коде это массивы NumPy формы `(n,)`, не вложенные списки. Сложение и длина — школьные; столбец пишем как <Eq math="vec(x, y)" />, когда умножаем на матрицу.

## Поворот на плоскости

Поворот на угол <Eq math="theta" /> задаёт матрица <Eq math="2 times 2" />:

<Eq display math="R(theta) = mat(cos theta, -sin theta; sin theta, cos theta)" />

Этого хватит на следующую главу. Повороты в пространстве, винты и <Eq math={'upright("SO")(3)'} /> появятся позже, когда робот перестанет быть плоским.

Прямая кинематика собирается из формул суммы углов — их стоит узнавать в лицо:

<Eq display math="cos(alpha + beta) = cos alpha cos beta - sin alpha sin beta" />

<Eq display math="sin(alpha + beta) = sin alpha cos beta + cos alpha sin beta" />

## Формула → функция

«Алгоритм» в этой книге — не сортировка и не оценка сложности. Это процедура: вход, выход, те же буквы, что в формуле. Матрица <Eq math="R(theta)" /> становится функцией `rot2`:

```python title="rot2.py"
import numpy as np

def rot2(theta):
    c, s = np.cos(theta), np.sin(theta)
    return np.array([[c, -s], [s, c]])
```

Полный файл можно гонять отдельно: поворот базисного вектора <Eq math="(1, 0)" /> на 90° должен дать <Eq math="(0, 1)" />.

```bash

```

## Что подождём

Не нужно закрывать заранее.

- **Физика** — силы, энергия, инерция. Перед динамикой, не перед геометрией руки.
- **Производные** — когда появится скорость и якобиан. Правило цепочки напомним на месте.
- **Графы, поиск, `A*`** — перед планированием траекторий.

Если якобиан сейчас звучит пусто, это нормально. К 2R он не нужен.

## Чеклист

Перед следующей главой стоит узнавать такие строки:

- угол в формуле — радианы, `38` в ползунке — градусы;
- <Eq math="q in bb(R)^2" /> — пара чисел, не «загадочное пространство»;
- <Eq math="cos(q_1 + q_2)" /> — косинус суммы, не произведение косинусов;
- `np.array([x, y])` — вектор, его можно сложить и умножить на матрицу;
- функция `fk(q)` возвращает <Eq math="p" />: вход конфигурация, выход точка.
